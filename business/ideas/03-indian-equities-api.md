# Indian Equities API

## Thesis

A normalized API for Indian stock fundamentals, quotes, events, peer groups, and sector snapshots.

## Customer

Fintech apps, analysts, finance creators, data scientists, student projects, and internal research teams.

## Product

- REST API for company profiles, ratios, quotes, financial statements, events, peers, and sectors.
- SDK examples and data freshness metadata.
- Webhooks for changed records or corporate actions.

## Data Inputs

Company master, identifiers, quotes, financial statements, events, peer mappings, sectors, and parse logs.

## Monetization

Usage-based pricing, developer tiers, team plans, and enterprise data contracts.

## MVP

Five endpoints over a licensed or permitted dataset: company, quote, ratios, events, and peers.

## Risks

Redistribution rights are the main blocker. API customers will expect clear licensing.

## Next Steps

Design the canonical schema and build a local API over the existing parsed payloads for internal validation.
